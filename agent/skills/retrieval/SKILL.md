# 取数流程

1. 不确定指标名、单位或可用维度时，先 `list_metrics()` 查目录，不要猜。
2. **区分财年与自然季度**：
   - "FY24Q2 / 2024 财年第二季度" → 财年口径（三家公司财年不同，见 system prompt 财年说明）。
   - "2024 年第三季度 / 自然季度" → `query_metric` 传 `period_basis="calendar"`，期间写 `2024Q3`。
   - 问题里两种都没有明说、且答案会因此不同时，用 status=clarify 先问清楚。
3. **单位换算规则**：库内金额统一为百万美元（usd_mn）。
   - 要说"亿美元"：数值除以 100（1 亿 = 100 百万）。
   - 要说"百分比"：比率乘 100。换算数字一律用 `calc` 产出，不要心算。
4. 标准取数一律用 `query_metric`（语义层编译 SQL）；表达不了（查附注、自定义连接）才用 `run_sql`。
5. 占比、增速、差值等派生数字必须 `calc`，结果进 store 后才能在 claims 里引用 rid。
6. 趋势类问题优先 `last_n` 取连续多期；对比两期变化用 `variance`。
