## 联想因子与确定性解释

| 因子 | 数据库计算 |
|---|---|
| 集团收入同比 | -24.1469% |
| 期末存货同比 / 环比 | -11.1297% / -10.8796% |
| DIO（同一平均余额口径） | 上年同期 47.0918 天 → 本期 57.8708 天，增加 10.7789 天 |
| 平均存货 | 上年同期 8584.6985 → 本期 7959.973 百万美元 |
| 单季 COGS | 上年同期 16771.318 → 本期 12654.361 百万美元 |

DIO 的数学关系：DIO = 平均存货 / COGS × 天数。平均存货虽减少，但 COGS 降得更多，两季天数相同，所以 DIO 增加。可精确分解：

Δln(DIO) = Δln(平均存货) − Δln(COGS) + Δln(天数)

= -0.0755558 + 0.2816683 + 0 = 0.2061125，数值恒等式残差约 1.1e-16。这是指标变化的数学解释，不是对需求冲击的因果证明。

Agent 可据此说“存货减少，但按该季度口径尚未体现周转天数改善；与需求收缩、库存调整的解释相容”。具体经营原因仍应结合 p2 披露，同时标注为管理层解释。
