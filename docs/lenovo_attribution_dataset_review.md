# 联想归因候选集审核：可用性与修订清单

审核日期：2026-10-05。对象：`data/eval/lenovo_attribution_candidates/` 的 50 条候选。未修改候选原文、未调用被测 Agent、未启动批量实验。

## 1. 裁定

**作为候选池可用；作为未经修订的正式归因评分集暂不批准。**

来源追溯、数值计算与题型覆盖有价值，不需要重新抽取 50 条。但参考答案存在已确认的逻辑错误、DB 支持状态不准确和评分输入不一致。应先修订，再选约 8–12 条做第一轮人工调优；不以凑齐全部候选为前提。

本集目前更擅长评测财务口径核验、指标分解与证据边界，尚不能单独代表广泛的经营归因能力。要测自主归因，需要把部分带完整解题步骤的 query 改写为开放业务问题。

- 对完全由数值及四则运算组成的 207 条公式，使用受限 AST 算术解释器独立重算，全部落在设定容差内。其余自然语言公式、分解选择与因果含义不在这个自动检查范围。
- 对重点案例，直接读取当前 DuckDB original 数据和 PDF 财务页，核对历史覆盖、毛利率、调整项目缺口及利润符号。

## 3. 优点

1. 来源 URL、完整哈希、页码与引用齐全，可复核，而不是一批无法追溯的模型作文。
2. 覆盖金额/比率、单季/累计、分部/集团、利润调节、营运资金与不可辨识性，足以支持第一轮多类型诊断。
3. 主动登记真实分部、现金流量表与调整项目的数据缺口，没有直接把合成 `facts_detail` 当作真实业务解释。
4. 多数案例含公式、数值容差与禁止无依据断言的要求，适合发展为可评分案例。

## 4. 已确认的问题与处理要求

### A. `ready` 仍要求不可见的答案：先重分类或删去强制项

`LV-FY2026Q1-GM-OI-DIVERGE-001` 标为 ready，但输入自己写明调整后经营利润是 DB 缺口；`must_include` 却要求认股权证 152.4 百万及调整后增长 10.3%。

`LV-FY2025Q4-Q4-COLLAPSE-VS-FY-001` 同样标 ready，却要求剔除当前 DB 没有的认股权证亏损 118.275 百万、认沽重估收益 143.430 百万，再算剔项后增长 30.2%。题面也只提到项目名称，没有提供两个金额。

处理：完整问题改为 needs_numeric_data；或者保留 DB 可完成的“毛利—经营利润—派生费用”分析，调整项目只列为后续应查询的证据，删除其强制命中要求。不要允许 Agent 检索经营解释来绕过缺数字问题。

`boundary_only` 也不是天然可测：例如 `LV-FY2026Q1-IDG-VOLUME-IDENT-001` 要求 IDG 利润与利润率变化，但当前 DB 没有真实 IDG 表，query 也未给这些数字。保留边界结论，不能强制评分未提供的细项。

### B. 存货 DIO 参考解释把分子、分母说反

`LV-FY2027Q1-INV-DIO-001` 数值基本正确，但 `must_include` 称“分母（平均存货基数变大）解释……”。在 `DIO=平均存货/COGS×天数` 中，平均存货是分子，COGS 才是分母。

处理：说明期末存货增长约 80% 不等于平均存货增长约 80%；DIO 同比由平均存货与成本的相对变化共同决定。删除错误的分母表述。

容差依据也需修订：0.05 天不足以覆盖 ±1 个季度天数带来的水平变化。题面已规定实际季度天数，就统一计算；若允许替代天数，评分器应重算该口径，不能用一个固定小容差同时接受所有口径。

### C. 现金余额不能否定营运资金占用现金

`LV-FY2027Q1-WC-CCC-001` 的“现金余额同比上升，与备货挤压现金相反”不是可靠推理。现金期末余额可以受借款、融资、其他经营流入、投资等影响；库存占用与现金余额增长可以同时发生。

更正（2026-10-05 selected_v1 审核）：三个选定余额的净变化应为 **5258.727 百万美元**，计算为 `6999.312+8469.213-10209.798`。原候选写入的存货差分多计 21.000、应收差分多计 1.000；本审核初稿沿用了错误的 5280.727，现同步修正。这不是经营现金流，更不能仅靠这个式子确定“主要由谁出资”。

处理：保留“应付增加在余额分析上抵消部分库存/应收占用”的确定性分析；现金余额仅作补充观察。结论明确缺少现金流量表、汇率/合并范围等调节，不能识别最终资金来源或否定现金压力。

### D. 毛利率案例含错误权重、数据近似与不严谨分解

`LV-FY2026Q3-GM-DRIFT-001` 的 `required_inputs` 使用 FY2025 毛利“2562.8/2795.0/2958.7 量级”，而当前 DB 精确值为 **2559.849 / 2795.750 / 2959.391** 百万美元。不能用近似量级支持严格小容差评分。

该案例的 `weight_effect` 写“Q1 权重从 25.1% 升至 23.2%”，数值和方向表述都错。按两年各自前九个月收入计算，实际 **29.6526% → 30.6245%**。

独立核对：FY2025 9M 加权毛利率 15.9617%，FY2026 为 15.0767%，变化 -0.8849 个百分点；本期三季度简单平均为 15.0675%。

处理：替换精确输入，区分 9M 与全年；“Q1 降幅最大”可保留，但要声称贡献最大，就写明确的贡献分解并勾稽。仅用 `Δ季度毛利率×某一年的权重` 会遗漏两年权重变化项，不能直接当完整分解。

### E. 历史覆盖起点写错，导致评分要求错误

`LV-FY2024Q2-Q2-QOQ-REBOUND-001`、`LV-FY2025Q2-DEFREV-RECORD-001` 写 DB 历史从 FY2022 开始。实际 Lenovo revenue、gross_profit、递延收入两科目均有 **FY2018–FY2027 的 37 季数据**，最早期末 2017-06-30。

处理：按案例目标时点之前的全部可见历史重算，不只取 FY2022 以后的子样本。十年历史仍不完整，但理由应是可见期间不足十年，而不是“只看得到三年”。递延收入此前峰值 3026.731 百万美元的结果在全历史检查后仍成立；其历史覆盖表述需要修正。

### F. 非 PC 收入的下界被写成上界

`LV-FY2025Q3-NONPC-46PCT-001` 将 ISG+SSG 占比约 31% 写成“可识别的非 PC 收入上界”。若这两个业务均按相同口径归入非 PC，它们只能提供已知部分的**下界**；IDG 内部还有非 PC 业务，合计可能更高。

处理：将 query 中“上界”与 gold 同时修正。约 15 个百分点的 IDG 非 PC 部分只能在接受管理层 46% 总比例且分母/范围一致的条件下作为推导，不是独立验证后的真实拆分。

### G. 收购案例不能把“方向相容”评分为已证明原因

`LV-FY2026Q4-INFINIDAT-001` 的报告期后事件思路有价值，无形资产增加 1005.272 百万美元也可核。但 query 问“最大科目变化”却没有限定比较科目，实际应收、存货、应付等变化都比无形资产更大；gold 称它为“唯一”相容信号过强。

`acceptable_variants` 又允许“存货/应收大增主要来自业务备货而非收购”，当前数字不能排除收购形成的资产或其他因素，不能作为正确的已证实归因。

处理：限定要比较的真实非流动资产科目，或改问“无形资产变化能否支持并唯一证明收购归因”。“本季摊销/减值仅约 0.5 百万”的比较缺少对应输入和页码，先删除或补齐核对，不纳入强制 gold。注意 2026-05 公告的“初始会计处理未完成”不能未经检查就当作 2026-08 仍未完成。

### H. 正经营利润被写成“经营层出现亏损”

`LV-FY2027Q1-PROFIT-SEQ-001` 的 gold 写“亏损出现在经营费用层”，但报表经营利润仍为 **+19.202 百万美元**；之后除税前为负。费用层侵蚀经营利润与首次出现净亏损是两个判断。

同时 DB 当前 `net_income=+477.592`，原公告本期为 **-477.592** 百万美元，这是业务数据符号缺陷。正负错误不是 harness 推理失败，应先修数据/登记隔离，不能要求模型根据正数算出负数。

处理：改正层级叙述；该题维持待补数/数据修复，先不用来评价归因质量。

### I. CCC 差异不等于管理层归因被证明错误

多条 CCC 案例把作者的时点/两点平均公式与公告数字比不上的结果，进一步写成“公告句把角色写反”“归因不成立”。公司可能使用不同余额范围、销售/采购基准或更细时间平均；当前候选也承认管理层口径未知。

处理：确定性 gold 仅要求“在题目指定公式下结果是什么，与披露未能对账；需要补充什么口径”。不要强制 Agent 宣称公司原陈述错误。原文若有文字歧义/翻译问题可单列来源问题，不能用选定公式证明所有其他口径都不成立。

CCC 题较多，第一轮选 1–2 条即可，避免优化成专门质疑公告的模板。

### J. 自动评分字段、事件分组与题面需整理

- 203 个 required_inputs 的 `db` 字段有 146 个字符串、57 个对象；313 个 calculations 有 268 个缺 `unit`。人可以读，自动评分难以可靠区分比例、百分比、百分点与天数。统一为结构化字段与单位。
- 引用定位字段只有页码、无源文件时，多文件引用有歧义；每条证据与计算输入都应能定位到 PDF+页码或 DB 查询+字段+期间。
- 当前 45 个事件族不能自动防泄漏：跨公告 CCC 系列、反复引用同一非现金调整事件等仍可能分在不同族。需要额外的 split_group/data_window 标记，不能机械按现有 family_id 随机分。
- 许多 query 已给金额、分解路线、公式甚至结论，如“说明整句的方向为何与数据相反”。这类保留为定向诊断题；自主归因题要删掉答案暗示。
- 参考答案仍有“经营利润全部增量来自费用层”等过度表述。例如 FY2026Q1 `ΔOI=214.628+75.712=290.340`，毛利与费用变化都贡献了改善，不能称全部来自费用层。
