## 联想 FY2027Q1 库存增长与周转分析

**数据来源**（合并报表，USD mn）：

| 指标 | FY2026Q1 | FY2027Q1 |
|---|---|---|
| 存货期初 | 7,923.80 | 11,720.90 |
| 存货期末 | 8,742.64 | 15,741.90 |
| 营业收入 | 18,829.9 | 26,942.8 |
| 销货成本（COGS） | 16,055.4 | 22,490.8 |

### 一、量化变化

**1. 存货同比增长**
- 期末存货同比：（15,741.90 − 8,742.64）/ 8,742.64 = **+80.1%**

**2. 平均存货**
- FY2027Q1 平均存货 =（11,720.90 + 15,741.90）/ 2 = **13,731.40**
- FY2026Q1 平均存货 =（7,923.80 + 8,742.64）/ 2 = **8,333.22**
- 平均存货同比 =（13,731.40 − 8,333.22）/ 8,333.22 = **+64.8%**

**3. 存货周转天数（季度，按 91 天计算）**
- FY2027Q1 = 13,731.40 × 91 / 22,490.8 = **55.4 天**
- FY2026Q1 = 8,333.22 × 91 / 16,055.4 = **47.2 天**
- 周转天数同比变化 = **+8.2 天（恶化约 17.4%）**

**4. 营收与 COGS 增速**
- 营收同比增速 =（26,942.8 − 18,829.9）/ 18,829.9 = **+43.1%**
- COGS 同比增速 =（22,490.8 − 16,055.4）/ 16,055.4 = **+39.9%**
- 存货增速（期末 +80.1%）明显快于 COGS 增速（+39.9%）

**5. 毛利率**
- FY2026Q1 毛利率 =（18,829.9 − 16,055.4）/ 18,829.9 = **14.7%**
- FY2027Q1 毛利率 =（26,942.8 − 22,490.8）/ 26,942.8 = **16.5%**
- 毛利率同比提升约 1.8 个百分点

### 二、现有数据能够支持的结论

1. **库存绝对水平显著上升**：期末存货从 8,742.64 增至 15,741.90 百万美元，增幅 +80.1%，远超营收（+43.1%）和 COGS（+39.9%）增速，说明库存积累速度明显快于销售消耗速度。

2. **周转天数恶化**：存货周转天数从 47.2 天升至 55.4 天，增加 8.2 天（恶化约 17.4%），直接反映周转效率下降。

3. **存货与 COGS 增速剪刀差**：存货增速（+80.1%）约为 COGS 增速（+39.9%）的两倍，这是周转恶化的量化证据——单位 COGS 所对应的库存量在增加。

4. **毛利率有所改善但不能完全解释库存积累**：毛利率从 14.7% 升至 16.5%，说明产品 mix 或定价能力有所提升，但毛利率改善与库存积累方向相反，不能解释为何存货增速远超销售增速。

### 三、现有数据不能支持（需进一步验证）的解释

以下假设在当前可获取的财务数据中**无法证实或证伪**，需依赖公司披露、管理层说明或行业数据：

1. **供应链主动备货 / 季节性因素**：存货大幅增长是否源于 AI 服务器、新品（如 Legion 系列）提前备货或关税/关税政策不确定性导致的主动囤货，现有数据无法判断。

2. **产品 mix 变化**：毛利率提升可能与产品组合向高毛利产品倾斜有关，但存货分项目明细（原材料 / 在产品 / 产成品）数据缺失，无法确认库存积压具体集中在哪个环节。

3. **产能或供应商变化**：若联想新增产线或更换供应商导致原材料储备增加，现有数据无法反映。

4. **存货跌价风险**：库存积压是否伴随跌价准备增加，需查看资产负债表附注中的存货跌价准备明细，当前数据中未获取该项。

5. **合并范围变化**：若 FY2027Q1 存在重大并表范围调整（如收购或新增子公司），可能部分解释存货跃升，需核对合并范围说明。
